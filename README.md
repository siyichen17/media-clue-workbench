# 全网线索工作台

面向媒体编辑的线索工作台 Demo。编辑可以从热搜和已收录报道里发现事件，打开后看材料和分析树，关注后回来接着看，决定处理时留下自己的拟题和下一步。

English: a newsroom workbench for discovering events from hot-search boards and archived coverage, then tracking and following them. Built as a frontend demo with a fixed dataset.

## 能做什么

- **发现热点**：报道线索按事件聚合，可按最近报道时间或最新收录时间排序。微博、百度沿用原始榜位和热搜原词。
- **看懂事件**：事件详情保留分析树和全部报道。来自热搜时会带上原词、平台和快照。
- **持续追踪**：关注表示接收变化。没有已看记录时显示「尚未查看」，不会把历史材料说成新进展。
- **留下跟进**：跟进表示准备处理，和关注分开。重复加入会提示已有事项。结束跟进要写简短结果，且不会自动取消关注。
- **沿用原有模块**：统计总览、同行监控、报告、可视化大屏、数据源、KPI 和告警仍然可以进入。

统计总览默认近 7 天口径为新闻 125、话题 12、媒体 8、热榜条目 11。同行监控同一窗口的全部媒体收录为 127。这些数字来自演示数据，不是实时采集。

## 技术栈

- React 19、TypeScript、Vite
- React Router
- ECharts
- 分析、对比和报告生成走本机接口，模型密钥只放在服务端读取的 `.env`，不会打进页面

演示数据截止 **2026-11-10 18:00**。页面上的时间以这个截止点为准，不使用电脑当前时间。报道、热搜和事件都是模拟种子，未收录不等于未发生，新入库也不等于新发生。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开终端里给出的本地地址，从 `/hot` 进入热点。

不配置模型时，列表、报道、关注和跟进记录都可以用。需要生成分析树或报告时，复制环境变量模板再填写：

```bash
copy .env.example .env
```

`.env` 已在 `.gitignore` 中，不要提交。

```bash
npm run build
```

## 数据边界

- 不编造环比、粉丝量、传播量，也不把不同平台的热度加总。
- 热搜保留平台原词和榜位。一个热搜对应多个事件时，先选择事件，再进入详情。
- 模型失败时保留上一次结果。报道查看和跟进备注不依赖模型是否可用。
